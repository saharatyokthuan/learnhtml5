📖 HTML คืออะไร?

HTML คือภาษามาร์กอัปมาตรฐานสำหรับการสร้างเว็บเพจ

HTML ย่อมาจาก Hyper Text Markup Language

  • HTML คือภาษามาร์กอัปมาตรฐานสำหรับการสร้างเว็บเพจ
  • HTML อธิบายโครงสร้างของหน้าเว็บ
  • HTML ประกอบด้วยองค์ประกอบหลายอย่าง
  • องค์ประกอบ HTML จะบอกเบราว์เซอร์ถึงวิธีการแสดงเนื้อหา
  • องค์ประกอบ HTML ใช้สำหรับระบุส่วนต่างๆ ของเนื้อหา เช่น "นี่คือหัวข้อ", "นี่คือย่อหน้า", "นี่คือลิงก์" เป็นต้น

📄 เอกสาร HTML อย่างง่าย

<!DOCTYPE html>
<html>
<head>
  <title>Page Title</title>
</head>
<body>

  <h1>My First Heading</h1>
  <p>My first paragraph.</p>

</body>
</html>

🔍 ตัวอย่างอธิบาย

  • คำประกาศ <!DOCTYPE html> ระบุว่าเอกสารนี้เป็นเอกสาร HTML5
  • องค์ประกอบ <html> เป็นองค์ประกอบหลักของหน้า HTML
  • องค์ประกอบ <head> ประกอบด้วยข้อมูลเมตาเกี่ยวกับหน้า HTML
  • องค์ประกอบ <title> ระบุชื่อเรื่องสำหรับหน้า HTML (ซึ่งจะแสดงในแถบชื่อเรื่องของเบราว์เซอร์หรือในแท็บของหน้า)
  • องค์ประกอบ <body> กำหนดส่วนเนื้อหาของเอกสาร และเป็นภาชนะสำหรับเนื้อหาที่มองเห็นได้ทั้งหมด เช่น หัวข้อ ย่อหน้า รูปภาพ ไฮเปอร์ลิงก์ ตาราง รายการ เป็นต้น
  • องค์ประกอบ <h1> กำหนดหัวข้อขนาดใหญ่
  • องค์ประกอบ <p> กำหนดย่อหน้า

🧩 องค์ประกอบ HTML คืออะไร?

องค์ประกอบ HTML ถูกกำหนดโดยแท็กเปิด เนื้อหา และแท็กปิด:

<tagname> เนื้อหาตรงนี้... </tagname>

องค์ประกอบ HTML คือทุกอย่างตั้งแต่แท็กเปิดจนถึงแท็กปิด:

<h1>My First Heading</h1>
<p>My first paragraph.</p>
Start tag Element content End tag
<h1> My First Heading </h1>
<p> My first paragraph. </p>
<br> none none
หมายเหตุ: องค์ประกอบ HTML บางอย่างไม่มีเนื้อหา (เช่น องค์ประกอบ <br>) องค์ประกอบเหล่านี้เรียกว่า องค์ประกอบว่างเปล่า องค์ประกอบว่างเปล่าไม่มีแท็กปิด!

🌐 เว็บเบราว์เซอร์

จุดประสงค์ของเว็บเบราว์เซอร์ (Chrome, Edge, Firefox, Safari) คือการอ่านเอกสาร HTML และแสดงผลอย่างถูกต้อง

เบราว์เซอร์จะไม่แสดงแท็ก HTML โดยตรง แต่จะใช้แท็กเหล่านั้นในการกำหนดวิธีการแสดงผลเอกสาร:

🏗️ โครงสร้างหน้า HTML

ด้านล่างนี้คือภาพแสดงโครงสร้างของหน้าเว็บ HTML:

<html>
<head>
  <title>ชื่อหน้า</title>
</head>
<body>
  <h1>นี่คือหัวข้อ</h1>
  <p>นี่คือย่อหน้า</p>
  <p>นี่คือย่อหน้าถัดไป</p>
</body>
</html>
หมายเหตุ: เนื้อหาภายในส่วน <body> จะแสดงผลในเบราว์เซอร์ ส่วนเนื้อหาภายในองค์ประกอบ <title> จะแสดงในแถบชื่อเรื่องของเบราว์เซอร์หรือในแท็บของหน้าเว็บ
