📖 โครงสร้างของ HTML5

ไฟล์นี้สร้างขึ้นมาเพื่อทดสอบความรู้ HTML5 ที่ได้เรียนมา ครอบคลุมตั้งแต่โครงสร้างพื้นฐานจนถึงการใช้งาน Semantic Tags ต่างๆ

เคล็ดลับ: HTML5 เป็นมาตรฐานเว็บสมัยใหม่ที่รองรับการทำงานบนทุกอุปกรณ์

บทนี้เรียนรู้เกี่ยวกับ โครงสร้างของ HTML5 พร้อมตัวอย่างการใช้งานจริง ซึ่งประกอบด้วยแท็กสำคัญดังนี้:

✨ Semantic Tags ใน HTML5

คุณสามารถใช้ <article> สำหรับเนื้อหาที่เป็นอิสระต่อกัน โดยแท็ก Semantic สำคัญๆ ได้แก่:

  • <header> — ส่วนหัวของหน้าเว็บหรือส่วนย่อย
  • <nav> — เมนูนำทาง
  • <main> — เนื้อหาหลักของหน้า
  • <section> — กลุ่มเนื้อหาที่เกี่ยวข้องกัน
  • <article> — เนื้อหาที่เป็นอิสระ (ข่าว, บล็อก)
  • <aside> — เนื้อหาข้างเคียง (sidebar)
  • <figure> — รูปภาพพร้อมคำอธิบาย
  • <footer> — ส่วนท้ายของหน้าเว็บ

เกร็ดความรู้

HTML5 ถูกพัฒนาโดย W3C และ WHATWG เพื่อเป็นมาตรฐานเว็บยุคใหม่ที่รองรับการใช้งานบนอุปกรณ์ทุกประเภท รวมถึงสมาร์ทโฟนและแท็บเล็ต
